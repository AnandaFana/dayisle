# 示例图

所有 PNG 均为应用本机运行后的真实界面截图，使用 `体验示例` 中由 `dayisle/demo.py` 生成的虚构内容，没有使用个人数据或示意图替代应用界面。

重新截图：启动独立数据目录，打开体验示例，再通过界面切换主题与子记录数量。示例日期按运行当天所在周生成，因此不同日期截图可能不同。

- `timeline-mint.png`：薄荷花园，主时间线，子记录收起。
- `timeline-paper.png`：纸上时光，嵌套记录预览。
- `timeline-cyber.png`：霓虹漫游，主时间线。
- `display-settings.png`：展示偏好与即时预览。
