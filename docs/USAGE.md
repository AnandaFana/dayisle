# 时间、统计与数据约定

## 时间与统计约定

- 普通任务有本地开始和结束时间，结束必须晚于开始；持续记录可不设结束日期。时间线按实际时间跨度绘制；月与季度刻度会按各月实际天数分配宽度。
- 子事件必须位于父事件时间范围内。缩短父事件时，如果会截掉子事件，保存会拒绝并提示原因。
- 日、周、月等显示区间使用左闭右开时间范围；日期选择器的结束日期包含整天。周从周一开始。
- 时间跨度不等于实际投入。一条横跨一周的事件，投入为零时，不会被算成工作了一周。
- **独立投入**只填写此事件自身的用时，不重复填写子事件已经记录的分钟数。父事件不会自动累加子事件进度或用时。
- 报告把手填投入归入**事件结束日期**；无结束日的持续记录按**开始日期**归属。跨周长项目建议按天建子事件；不会猜测跨期用时分配。
- 数量统计包含与所选区间相交的父、子事件；甘特图显示当前层级及其直接子记录预览；搜索也查找这些子记录，命中子记录时保留父事件作为上下文。概览卡片与分类分布使用整个选定时间区间与分类，不随单个层级或搜索改变。
- 完成数量与状态是生成报告时的当前值，不是历史日期的状态快照。
- 全部生活报告包含区间内日记。任一分类报告（例如工作周报）均不包含日记。
- 日记与报告在页面中按安全的纯文本展示；可以书写 Markdown 源文，导出的 `.md` 可在 Markdown 编辑器中排版。

## 数据与备份

正式内容保存在 **`data/records.jsonl`**。每行是一笔事务，包含版本号和一组记录变更，文字采用 UTF-8，方便人工检查与后续迁移。

```json
{"revision":2,"changes":[{"collection":"events","record":{"id":"…","title":"…","parent_id":null,"start":"2026-09-11T09:00","end":"2026-09-11T10:00"}}]}
```

这只是格式示意，实际记录包含其他字段；不要把示意行直接写进数据文件。文件保存采用进程独占锁、线程锁、版本校验和 `fsync`。如果启动时发现不完整或损坏行，会停止并保留原文件，不会默默丢弃历史。

在 **我的空间 → 数据握在自己手里**：

- **完整 JSON 备份**：下载包含当前记录（含回收站）的自包含快照；适合迁移和恢复。
- **导入备份**：按 ID 合并，内容相同的跳过；相同 ID 内容不同时整次拒绝，防止覆盖当前数据。完整恢复到旧版本应使用空数据目录启动，再导入旧备份。
- **CSV 导出**：事件和日记分别导出，适合 Excel 分析；子事件保留 `parent_id`。对可能被表格软件执行为公式的文本前置单引号；无损恢复用 JSON。
- **回收站**：删除事件会同时移出其后代，但不会删除日记正文。恢复某个子事件时会恢复必需的父事件和分类；不会恢复无关的兄弟事件。删除时解除的日记关联可在日记编辑中重新选择。

JSON 快照不是全部修订历史。需要保存完整审计历史时，停止服务后另行复制整个 `data` 目录。JSONL 保留被修改和移出视图的旧内容。当前版本不提供永久擦除。

页面样式、展示偏好和未提交草稿保存在当前浏览器的 `localStorage`，不在 JSON 备份内。清除浏览器数据会删除这些草稿，但不会影响已保存到 JSONL 的内容。多窗口保存冲突会保留输入并提示核对最新数据。

这是无账户的本机应用，默认仅监听 `127.0.0.1`；没有上传、遥测、云同步或外部 CDN。数据与草稿为明文，本机其他有权限的程序也可读取。手机布局指窄屏适配，不表示已经开放手机远程访问。
